参考入口：[App.tsx](https://github.com/farion1231/cc-switch/blob/43e1d99084ed9b2f5dc252fd35c5adaf29d6876e/src/App.tsx)、[index.css](https://github.com/farion1231/cc-switch/blob/43e1d99084ed9b2f5dc252fd35c5adaf29d6876e/src/index.css)、[UsageDashboard](https://github.com/farion1231/cc-switch/blob/43e1d99084ed9b2f5dc252fd35c5adaf29d6876e/src/components/usage/UsageDashboard.tsx)、[UsageHero](https://github.com/farion1231/cc-switch/blob/43e1d99084ed9b2f5dc252fd35c5adaf29d6876e/src/components/usage/UsageHero.tsx)、[ProviderCard](https://github.com/farion1231/cc-switch/blob/43e1d99084ed9b2f5dc252fd35c5adaf29d6876e/src/components/providers/ProviderCard.tsx)。截图只说明资源中的视觉，不用它推断完整能力。

不沿用供应商启用/切换、模型接入、MCP/Prompt/Skill 编辑等交互。将原横向供应商卡片转为独立账户卡片；Agent 作为用量筛选维度。参考不等于搬用品牌、全部代码或资源，Providock 使用自己的标识和信息架构。

## 2. 信息架构

顶部固定应用栏：Providock 标识、主导航“用量 / 账户 / 会话 / 数据源”、右侧同步状态和设置。设置作为抽屉/独立页管理隐私、数据、价格、导出和网关。首版不提供模型聊天入口。

初始窗口约 1180×800，最小 960×640。主内容最大宽 1440，边距 24；窄窗边距 16，摘要由六列折为三列/两列，账户行按内容折叠。仅明细表可横向滚动，不能整个应用页面横向溢出。

## 4. 用量页

第一行筛选：日期范围（今天/7天/30天/自定义）、Agent、模型、项目、数据域，右侧同步/导出。默认数据域为本地日志；网关有潜在重叠时明确单独切换。筛选常驻页面状态，详情抽屉关闭不丢失。

当前用量页已提供八 Agent 标签、数据源/模型、今天/7天/30天/全部/自定义日期筛选；按截图参考将总 Token、请求数、费用与 fresh/output/cache create/cache hit/缓存命中率集中在摘要区，下方展示趋势和 Agent 分布。「数据采集与调度」折叠区和设置页均提供持久化的两类开关；「显示刷新」默认 30 秒，可关闭或选择 5/10/30/60 秒，明确与 60 秒采集区分。项目/数据域筛选、导出和详细表格仍是规划项。日期筛选用本地日历边界；当前日趋势桶为 UTC，界面明确标注，统一可选时区待后续实现。

摘要含总 Token 已知小计、已知请求数和当前定价估算；下方六卡为新增输入、输出、缓存创建、缓存命中、成本估算、加权缓存命中率。所有卡共用时间筛选并显示实际起止与覆盖率，费用两位小数，未知保留为空。组成事件见下方计量明细。

趋势图切换 Token / 费用；按日/小时聚合，使用同一时区。缓存细分可折叠；缺失数据是断点或未知标记，不画成 0。图表有表格等价内容。Agent/模型排行和明细表放在下方，明细列为时间、Agent、模型、会话、输入、输出、缓存读/写、费用、来源/质量。

摘要“请求数”仅在 request_count 覆盖充分时另列，混合回合/消息记录默认叫“计量记录”。默认不把 API 等价估算展示成订阅实际花费。

## 5. 账户页

页首“全部 / API 付费 / Coding Plan”、平台/区域、状态筛选，右侧“添加账户”和“全部刷新”。横向账户卡片从左到右为平台图标、别名和区域、产品类型/掩码凭据、指标、最近刷新和操作菜单。

API 行：可用余额为主，币种清晰；充值/赠金/授信等展开。Coding Plan 行：每个窗口独立显示“5 小时剩余 42% · 2 小时后重置”等；实际只有月度 Credits 就显示月度 Credits。两者并存账户在同一卡片分组显示，不让用户为同一平台重复添加。

账户抽屉含钱包 scope、多 Key/组织/项目、窗口完整列表、查询来源和兼容状态、凭据更新、手动共享钱包关联、删除本地记录。余额排序同币种内进行，禁止把 CNY/USD 直接比较。没有官方查询能力时保留账户名/凭据管理，主列表不给空的余额数字占位。

“添加账户”步骤：平台与区域 → 账户类型 → 凭据类型及最小权限说明 → 保存并只读验证。凭据输入采用密码框，无默认明文回显；保存后用别名和掩码确认。这里不出现选择要接入哪个 Agent 的步骤。

## 6. 会话页与正文

会话列表可按 Agent/项目/时间搜索，展示父子关系、Token 小计、最后活跃和数据完整性。搜索默认只查索引中的元数据，不在后台扫完整正文。会话标题也可能敏感，提供隐藏标题与项目路径的隐私显示模式。

详情抽屉先展示统计、模型、子 Agent、来源定位；正文区域默认为“对话查看未开启”。开启后仅该源/会话读取文本，支持分页与工具块折叠。原文件删除、权限不足、版本不兼容时分别提示原因；统计仍保留。

安全 Markdown 仅渲染白名单，脚本/HTML 禁用，远程图片不自动加载；用户点外链前显示目标域名，使用系统浏览器打开。工具调用内容不能变成可点击执行命令。复制正文和导出正文必须由用户主动触发。

## 7. 数据源与设置

数据源卡片：Agent、发现目录（可隐藏）、协议/schema、兼容状态、最早/最新记录、同步时间、读到的字段、子 Agent覆盖、错误详情。提供启用/暂停、选择目录、重新扫描；“重新扫描”明确幂等，不能等同清空。

可选网关独立区域默认关闭，显示监听、目标、捕获范围、手动配置说明和流量域。开启前解释流量将经过本进程；不会声称已经自动接管 Agent。

设置：外观、隐私/正文开关、统计保存、账户刷新周期、价格版本、导出、本地数据清除。数据清除区分统计数据、账户快照、账户条目/凭据；最终操作文字明确范围。数据源停用不删除已有数据。

## 8. 状态表

| 状态 | 页面行为 |
| --- | --- |
| 首次空白 | 引导发现目录/添加账户，不显示全 0 仪表盘 |
| 已发现但无 usage | 显示“发现会话，未发现可计量记录”，解释源能力 |
| 正在扫描 | 显示文件数/记录数进度，允许取消；已有数据仍可浏览 |
| 某源不兼容 | 单源告警，不阻塞其他源；旧数据带上次成功时间 |
| 账户暂时失败 | 保留最近快照，标过期和刷新时间 |
| 无官方查询能力 | 隐藏指标；编辑页说明，不诱导更换 Key 猜余额 |
| 凭据错误/权限不足 | 明确“更新凭据”或所需权限，不显示零余额 |
| 日期无记录 | 显示所选范围为空，允许重置筛选 |
| 字段未提供 | 用“— / 未提供”，tooltip 含原因 |

## 9. 无障碍与验收

完整键盘导航、可见焦点、Escape 关闭抽屉、焦点返回触发按钮，禁用状态说明原因。按钮不少于 32px 可点击区域，正文对比度目标 WCAG AA，图表不只靠颜色，低动态偏好减少动画。

验收截图覆盖纯黑主题、最小窗口、100%/150%/200% Windows 缩放、中文长别名、多币种、多窗口、无权限、过期、空状态和正文关闭。离线原型见 [dashboard.html](../prototypes/dashboard.html)，只评审布局与流程，不代表数据接入或生产代码。

## 2026-10-12 实现增量

按用户提供的 cc-switch 使用统计截图增强摘要、蓝色分段筛选、浅深色和卡片层级，保留八个 Agent、来源、模型、日期与调度开关。趋势支持新增输入、输出、缓存读写以及分币种估算费用，未知桶保持断点，并提供表格等价内容。当天按 UTC 小时分桶后以本地时间标注，其他范围使用明确标注的 UTC 日桶。

模型/Agent 汇总和每页 20 条计量明细使用同一筛选范围；无可靠 HTTP 状态或耗时的日志不虚构这些列。模型行和页首可打开定价对话框，填写 USD/CNY 每百万 Token 四分量费率；空白是未知、0 是明确免费，显示完整估算覆盖率。项目/数据域筛选及导出仍未提供 UI。

账户页面保留最近快照；旧凭据不存在于新本地文件时提示重新输入一次 Key。添加和更新表单说明明文保存在本机、重启直接使用、不访问系统钥匙串。前端仅收到掩码/指纹，不回显 Key。页面错误边界保留导航与重试按钮。

## macOS 菜单栏

关闭主窗口继续后台运行。原生菜单展示最近 24 小时本机日志已知 Token 小计、输入/输出/缓存命中、八 Agent 小计和采集状态；每 30 秒及同步事件刷新。菜单提供打开、立即同步和退出，Dock 点击恢复原窗口，⌘Q 退出。未知显示 —，滚动时间范围与主页面「当天」筛选不同，均明确标示。使用 macOS 系统原生菜单颜色，不改变系统菜单栏主题。

## v2.0.3 增量

macOS Overlay 顶栏隐藏标题，红绿灯与纯黑应用区域一体，顶栏可拖动。设置的 Agent 复选同步过滤用量选项卡、来源、汇总、趋势和明细；至少一个可见。渐变曲线左轴 Token、右轴虚线估算成本；多币种选择同步成本轴、提示和数据表，缺少所选币种保留断点。

设置新增「软件更新」：当前版本、自动检查开关、检查按钮、新版说明及下载/安装进度。其他页发现新版显示应用内横幅，可稍后处理。用户点击「下载、安装并重启」后才执行，失败给出重试，安装成功但重启失败时单独重启。浏览器预览禁用原生能力。详细运行策略见 [更新规范](APP_UPDATES.md)。

## v2.0.4 增量

共享深色 Select 用于所有单选下拉，触发器有图标/文字/箭头，菜单有选中勾和高亮。支持方向键、Home/End、文字查找、Enter/Space 选择、Escape、Tab 及外部点击关闭，保持可见焦点；dialog 内菜单保持顶层，菜单高度/位置适应视口。模型名称仍为可输入的自动补全字段。

默认当天统计明确标起止时间，第六张成本卡与顶部当前估算一致。移除已报告成本、最近采集结果面板、页脚右侧说明及无用 CSS；诊断仍在数据源页。账户来源改短标签/可折叠原始详情，长字符串换行，窗口的标题/百分比/重置分行，窄窗刷新信息换至底部。

模型定价页首加入 AIHOT 导入按钮、来源链接、忙碌/失败/成功状态和未匹配列表；成功后刷新规则和用量估算。规则展示来源、官方链接与更新时间/汇率日期，人工保存后视为手动规则。金额两位小数，费率输入不做两位截断。

## 2026-10-13 当前本地界面

本节更新此前页面布局描述。顶部保留用量/账户/会话/数据源和设置；标题右侧集中主要操作。设置左侧四组：采集与刷新、Agent 显示、软件更新、关于与隐私。采集入口统一进入设置，用量页仅保留模型定价和手动同步。

九个 Agent 可显示选择；用量增加滚动 1/3/6 小时和 datetime-local 起止输入，点击应用后才更新实际区间。汇总、趋势、维度和明细使用同一筛选；范围不超过 48 小时用小时桶，其余按 UTC 日桶。自定义为 [from,to)，结束时刻不包含。未应用编辑不改变数据。

移除常态覆盖率、重复口径、副标题和无必要过程解释；用量/定价/设置使用少量 Hint（鼠标悬停、键盘焦点可读），详细来源可折叠。仅在不完整时显示部分数据/估算标记；未知、无价、过期和失败仍显式展示。

定价先 Agent/来源/模型，再获取 AIHOT 或公开官网价格，填入四分量表单，核对保存。官网模型辅助为可选展开区域，明确选账户、模型和费用，独立按钮触发；不自动使用账户。Codex 添加账户只显示本机 ChatGPT 登录说明，无秘密输入。
