# 隐私、密钥与只读边界

## 1. 默认数据范围

仅扫描已知 Agent 目录及用户添加的根目录，采集 Token、模型、发生时间、会话身份、父子关系和项目引用。项目路径、会话标题也可能敏感，提供隐藏和不索引选项。默认无遥测、云上传、自动正文搜索和远程资源加载。

默认不将 prompt/reply/tool output 复制进自有数据库。用户选择开启正文查看后，从原始会话按需读取，分页返回，抽屉关闭或切换源时释放缓存。统计依赖的文件中虽然含正文，解析器应跳过不需要的字段，禁止将整条原始 JSON 写入诊断。

可选正文查看包含工具块，但只是查看，不执行命令。没有源正文就显示缺失，不用统计数据“恢复”不存在的内容。后续若要正文全文索引或持久化，必须另做明确产品选择和存储加密方案，不默默改变当前默认。

## 2. 凭据

macOS 使用 Keychain；Windows 使用系统凭据库或等价系统保护方案，具体 Rust 库在 P0 验证。SQLite 仅保存 credential_ref、类型、掩码和本机 HMAC 指纹。Keychain 不可用时不回退到明文文件；可提供仅本次内存使用，不得将其误标“已安全保存”。

前端只在提交表单瞬间传递凭据，随后清空输入，后端响应不回显。禁止通过 URL query、命令行参数、日志、异常原始请求、剪贴板自动复制或开发工具持久状态保存秘密。凭据需要用于请求时在后端短期解封，尽可能缩短生命周期；不能宣称能完全消除进程内存风险。

账户删除处理共享凭据引用；清除本地凭据不等于平台撤销 Key。备份/导出默认不含秘密；首版不提供“全量 Key 导出”。如以后需要迁移凭据，应独立设计用户口令加密导出，不依赖便携版复制凭据库。

## 3. 只读采集

源文件以只读方式打开，不修复、不移动、不改写格式；源 SQLite 不 checkpoint、不迁移、不写 WAL。新用户界面不能触发 Agent CLI 执行任何 prompt。需要只读进程协议（例如官方 App Server）时限制可调用方法，并在测试中拦截 turn/start 等变更方法。

路径规范化并处理符号链接/Windows junction；拒绝逃逸已选择根目录的任意路径请求。IPC 中的 session_ref 由后端查索引解析，不接受前端任意传系统路径读取。防止正文接口成为通用本机文件读取器。

## 4. 网络查询与网关

账户查询使用准确 host allowlist、TLS 证书校验、有界超时/响应体；跨 host 重定向不携带 Authorization。首版不允许任意脚本和任意 URL 携带密钥。诊断只记录 HTTP 状态、平台错误码和脱敏原因，不记录完整账户响应。

官方本机 Server 连接只接受用户配置或确认的 loopback 实例，协商身份和版本，令牌保存在系统凭据库。不会扫描局域网或向任意同端口进程发送厂商 Key。Kimi 本机 Server token 与推理 Key 不混用。

网关默认关闭，仅绑定 127.0.0.1/::1；本机随机访问令牌、明确上游、目标 allowlist、连接/并发/体积上限。保护 HTTP Origin/CORS，不能把浏览器任意网页当授权调用者。无法验证客户端身份时不暴露敏感管理 API。网关采集内容默认不落盘，usage 元数据可存。

转发会实际处理推理请求，必须保留取消、回压、超时与工具协议。不能静默自动重试造成额外账单。失败提示说明网关进程状态与捕获范围，不能保证网关关闭后 Agent 仍能访问配置的本机地址。

## 5. 不可信正文与导出

日志和对话都是不可信输入，可能含 prompt injection、HTML、控制字符、恶意链接和超大数据。它们只作为数据，不能指导应用执行操作。禁用脚本、iframe、事件处理器和自动远程图片；Markdown 安全渲染、长度限制、分页、代码块纯文本。外部链接仅允许安全协议并交系统浏览器。

统计导出采用用户选择的文件位置，预览时间、路径脱敏、字段和范围。CSV 对以 =、+、-、@ 等开头的文本防公式注入；JSON 带契约版本、质量、币种、scope 和覆盖信息。正文导出为单独明确操作，默认不随统计导出。诊断包不得含密钥、Cookie 或正文，生成前显示文件清单。

## 6. 存储与清理

自有 DB 使用用户专属应用目录和系统文件权限；数据库统计元数据不承诺自带全文加密。系统磁盘加密可作为用户环境能力，但不能把它宣传成应用已加密数据库。崩溃报告、应用日志和自动备份不得附带正文缓存或秘密。

清理统计明细默认保留去重身份；彻底清空则删身份/游标并提示可重新导入。清除账户条目同时按引用清理凭据，历史快照是否保留由明确选项决定。文件删除不保证底层介质不可恢复，文案不使用“永久安全擦除”的虚假保证。

## 7. 必测安全场景

恶意会话 Markdown、远程图片、javascript 链接、CSV 公式、目录逃逸、junction 循环、凭据库锁定/拒绝、跨域跳转、伪造本机服务、超大 JSONL/HTTP 响应、未经启用的网关、端口冲突、日志泄密扫描。测试密钥必须是合成标记，不能复用真实 Key。
