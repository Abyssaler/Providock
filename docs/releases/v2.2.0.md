# Providock v2.2.0

本版修复官网价格获取，并新增 New API / One API 中转站账户查询。

- 官网价格采用 HTML5 表格解析，正确处理合并单元格、横表、多币种及实时/Batch 价格；已联网验证 MiMo、DeepSeek、智谱三个官网。
- 候选价格携带完整时段与输入/输出组合分档；支持编辑、保存和精确边界估算。DeepSeek 可排除中国 2026 节假日，未覆盖年份或缺少判定用量保持未知。
- 模型辅助改为提取完整策略并与官网结构化结果独立核验，数值证据校验更严格；仍为主动选择后的单次付费 API 请求，结果待用户核对保存。
- 添加 New API / One API 时可配置 HTTPS 站点和凭据。New API 推理 Key 查询 Key 额度，站点明确授权并返回 user_quota 时另显示账户余额；个人访问令牌和用户 ID 查询账户余额/额度。原始站点额度默认不当作现金，明确配置换算后才显示 CNY/USD。
- 无限额 Key、负余额、错误和旧快照范围保留；中转站请求固定到用户指定公网站点并拒绝重定向，不发送推理请求。

同 v2 升级保留既有账户、凭据、价格和统计，数据库 schema 不变。新策略以可选 JSON 字段追加；使用组合分档后不建议降级到旧版（旧版无法解释新条件）。九种本地 Agent、六个既有账户平台与托盘行为继续支持。

验证范围：本机前端、Rust 全量回归、类型/格式/构建、三个官网实际下载解析；发行包来自同一提交的 macOS ARM64 / Windows x64 CI。中转站为官方协议与合成样本验证，未使用真实站点账户；模型辅助未做真实付费调用。Windows 原生新流程、完整安装/更新/休眠、网关转发及通用迁移/性能原有未验边界继续保留，不因 Release 标签视为已完成。

macOS 包为 ad-hoc 完整性签名，未 Apple Developer ID 公证；Windows 未 Authenticode。安装/更新包附 minisign 签名及 SHA-256。用户自行安装，本轮不替换本机正式应用。
