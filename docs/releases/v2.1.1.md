# Providock v2.1.1

Windows 关闭主窗口后隐藏到托盘，保持后台采集和账户刷新（仍遵循各自开关）。左键托盘图标，或右键选择「打开 Providock」恢复窗口；右键选择「退出 Providock」才完全退出。

托盘使用彩色应用图标，适配明暗任务栏。恢复时解除最小化并聚焦原窗口。macOS 原有菜单栏、Dock 恢复和 ⌘Q 退出行为保持。

Windows x64 使用 `Providock_2.1.1_x64-setup.exe`，Apple Silicon macOS 13+ 使用 `Providock_2.1.1_aarch64.dmg`。v2.0.3 及以后可从「设置 → 软件更新」升级；安装前请从托盘真正退出旧应用。本版无 schema 变更，保留统计、账户、凭据、设置和本机价格规则；v1 数据不自动迁移。

本版只调整 Windows 生命周期，九源解析器和账户端点不变。Windows 完整安装/覆盖/实际更新、所有缩放及休眠恢复仍需分别验收；Mac 无 Apple Developer ID 公证，Windows 无 Authenticode。版本发布标记不代替未验项。验证及发行依据见 [本版记录](../research/validation/2026-10-13-windows-tray-v2.1.1.md)。
