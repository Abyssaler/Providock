# Providock v2.0.4

本版统一深色下拉菜单，修复账户额度卡片排列，并新增 AIHOT 人民币模型价格一键导入。

## 改进

- 用量、账户、会话筛选及表单下拉菜单统一深色圆角样式，带勾选、悬停与键盘导航。
- 费用显示统一为两位小数，底层计算精度不变；新增成本估算卡片及明确统计时间范围。默认仍为本机当天零点至最近刷新，所有指标跟随上方筛选。
- 删除「已报告成本」的源解析、入库写入、聚合、IPC 与导出字段；移除用量页「最近采集结果」和页脚右侧提示。采集调度和数据源页诊断保留。
- Kimi 账户来源信息改为友好名称、可展开详情，长文本自动换行；每个额度窗口独立呈现标题、百分比、重置时间和进度条，窄窗自动调整。
- 模型定价新增「一键导入价格」，从 https://aihot.news/leaderboard 为本机已用及当前填写模型匹配 CNY 价格，展示来源更新时间、汇率日期和未匹配模型。
- 保留手动、分档、特定来源与停用规则；可刷新未修改的 AIHOT 规则，保留历史版本。未知价格留空，页面不兼容或导入失败时已有价格不变。
- 重写 README，同步统计、定价、隐私、架构和兼容文档。

## 下载与升级

Apple Silicon macOS 13+ 使用 DMG；Windows x64 使用 NSIS EXE。v2.0.3 可在「设置 → 软件更新」检查并下载、安装、重启，无需卸载；v2.0.2 及更早版本手动替换应用包一次。同 v2 数据、账户、凭据与既有价格规则保留。

本版不迁移或删表；旧数据库自报费用列仅为兼容保留，业务不再读取/写入。服务层统计导出契约升为 `providock.statistics.v2`，不含自报费用字段；导出仍未接 UI。

价格导入仅获取公开页面，不发送本机模型列表、日志或 Key。按来源公布的人民币值及汇率日期导入，不推断缓存创建、长上下文或时段优惠；API 等价估算不是平台账单。Key 仍按用户选择存在本地独立明文凭据文件。

## 验证边界

macOS 原生 UI、隔离库价格导入、未知/零价区分、规则保护、批量回滚及精确金额回归已验证。正式发行的代码 SHA、双平台 CI、资产签名和安装核验见[本版记录](../research/validation/2026-10-12-release-v2.0.4.md)。

Windows CI 不等于 Windows 实机；Windows 原生安装/更新、多比例缩放仍待验。Mac 有 ad-hoc 签名，尚无 Apple Developer ID 公证；Windows 尚无 Authenticode。原有八 Agent、账户凭据策略及更新公钥保持。
