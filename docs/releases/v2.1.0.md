# Providock v2.1.0

新增 DeepSeek Harness、Codex 官方订阅额度与更精确的统计时间范围，统一精简界面和设置布局。

## 新功能与改进

- 保留黑色/黄绿风格和顶部导航，统一四页标题、主要操作和卡片间距；设置改为左侧分组。重复说明移至少量悬停/键盘提示及折叠详情，未知、过期和部分数据仍清晰显示，缓存创建指标保留。
- 用量新增滚动最近 1、3、6 小时，以及本机自定义起止日期时间；点击应用后统一更新汇总、趋势和明细。无效区间不会替换上一有效统计，48 小时以内使用小时趋势。
- 新增 DeepSeek Harness 的本地 session v3/v4 JSONL/.zstd 只读采集，识别重试、压缩摘要、分叉继承和多代/副本，避免重复统计。可在「设置 → Agent 显示」勾选；已有显示选择保持。
- 添加账户支持「Codex / ChatGPT 官方额度」：使用本机官方 Codex 当前的 ChatGPT 登录，无需 API Key。只读查询额度窗口，不复制 OAuth 令牌、不发起对话。需先在官方 Codex 登录；CLI 自定义路径可设置 CODEX_CLI_PATH。
- AIHOT 导入改为先选择 Agent 和模型，再获取该模型候选报价、核对保存；不会批量改写其它模型。
- 可输入公开计费官网 HTTPS 链接，优先用程序解析静态价格表；也可主动选择已有 DeepSeek、GLM、OpenRouter API Key 账户和模型，执行一次普通 API 辅助解析。公开价格文本会发送给所选模型并产生 API 费用；结果仍需核对保存，无工具或代理循环。DeepSeek/OpenRouter 可读取模型列表，GLM 直接输入模型 ID。
- 修复添加账户验证后列表快照未及时刷新的问题，优化会话时间及数据源长路径显示。

## 下载与升级

Apple Silicon macOS 13+ 使用 DMG；Windows x64 使用 NSIS EXE。v2.0.3 及以后可在「设置 → 软件更新」检查并下载、安装、重启；更早 v2 版本手动替换应用包。同 v2 统计、账户、凭据、价格规则和显示设置保留。本版不改变数据库 schema；v1 标识独立，不自动迁移。

API Key 仍按用户选择在本机独立文件明文保存，不访问系统钥匙串。日志采集、额度查询与可选价格辅助为独立功能；没有价格不等于免费，API 等价估算不代表订阅账单。
