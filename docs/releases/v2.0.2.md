# Providock v2.0.2

2026-10-12 · 正式 Release

本版修复新增账户后的白屏和钥匙串授权问题，增强按模型统计与自定义成本计算，统一纯黑界面，并加入 macOS 菜单栏后台运行。

## 变化

- 账户快照 IPC 字段统一为 camelCase，添加账户后可正常显示；页面错误隔离保留导航和重试。
- API Key 按用户选择明文保存到应用数据目录独立 credentials/keys.sqlite3，不访问 macOS 钥匙串。重启直接使用；Unix 目录/文件为 0700/0600，Windows 继承用户目录 ACL。已有 v2.0.0 账户与快照保留，需重新输入一次 Key；旧钥匙串条目不读取、迁移或删除。本地明文文件不宣称加密。
- 用量总览增加模型/Agent 统计、分页计量明细和输入/输出/缓存分量趋势；支持按 Agent、精确模型及可选来源填写每百万 Token 四分量价格，USD/CNY 分开计算。未知价格不冒充免费，当前价估算不改写历史费用。
- 全应用纯黑背景、白字和黄绿强调；应用图标采用原创 P、停靠条和状态点设计。
- 修复旧 CSS 覆盖曲线颜色的问题：输入蓝、输出绿、缓存命中紫、缓存创建橙。曲线圆滑且不越过真实数据区间，保留缺失断点、图例开关和等价数据表。
- macOS 关闭窗口后继续后台运行。菜单栏展示滚动最近 24 小时本地日志小计、八 Agent 用量及采集状态，并提供打开、立即同步和退出；⌘Q 或退出结束程序。自动任务仍遵循各自持久化开关，不安装登录启动项。Windows 维持关窗退出。

## 安装

Apple Silicon Mac 下载 Providock_2.0.2_aarch64.dmg（macOS 13+）；Windows Intel/AMD x64 下载 Providock_2.0.2_x64-setup.exe。退出旧应用后手动覆盖安装，保留 io.providock.app 数据目录；无需清理 Agent 日志。当前没有应用内自动更新入口，旧 v1 数据域不自动迁移。

下载附 SHA256SUMS.txt、公钥及 Tauri/minisign 签名；Mac 应用有严格验证的 ad-hoc 完整性签名，尚无 Apple Developer ID 公证或 Windows Authenticode。Windows 依赖 WebView2。

## 验证边界

52 项前端、322 项 Rust 测试通过（2 项真实环境测试忽略），账户 IPC 共享夹具、重启凭据持久化、独立精确成本计算、菜单栏时间范围/未知/分域和曲线区间有回归验证。Mac 原生关窗/恢复/退出的人工界面冒烟因电脑控制权限未授予而未完成；本次双平台 CI/发行资产核验详见 [验证记录](../research/validation/2026-10-12-release-v2.0.2.md)。

八个 Agent 的现有适配范围不变，详见 [兼容登记](../research/compatibility-register.md)。Windows 原生实机、真实账户联网、睡眠唤醒和性能基准仍未验收；Claude Desktop 网关仅有 usage 解析层，转发本体未实现；统计导出/清理 UI、通用升级保留仍有缺口。正式标签不代表上述项目已完成。本机记录与估算不能替代平台账单。

发行资产只取同一版本提交成功的 macOS ARM64 / Windows x64 CI，不包含本机数据库、日志、账户配置或签名秘密。原 v2.0.0 标签和资产保持原样。
