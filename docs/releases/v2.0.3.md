# Providock v2.0.3

本版修复 Agent 展示设置保存失败、恢复趋势图多币种切换，并加入 GitHub 正式 Release 更新通知和应用内签名安装。

## 改进

- macOS 顶栏与纯黑界面一体化；设置可选择用量页展示的八个 Agent，至少保留一个。
- 用量页顶部重新排版；趋势加入渐变、独立成本右轴虚线、悬浮提示与图例，币种分别查看，未知值保留断点。
- 模型价格支持北京时间工作日高峰/空闲与长上下文整请求升档；法定节假日暂不单独剔除，条件未知时不估算。
- Kimi Code Coding Key 直连查询 5 小时/7 天额度；GLM 认证失败与无套餐状态明确区分。已有局部 macOS 真实凭据验证，不代表所有账户平台均实测。
- 设置新增软件更新：默认启动及每 6 小时检查，恢复窗口时补查到期更新；发现新版在应用内通知，点击后才下载、验证签名、安装并重启。可关闭自动检查或手动检查。

## 下载与升级

Apple Silicon macOS 13+ 使用 DMG；Windows x64 使用每用户 NSIS EXE。Tauri/minisign 签名与公钥用于独立验签，SHA256SUMS 用于完整性核对。Mac 应用有 ad-hoc 签名，没有 Developer ID 公证；Windows 没有 Authenticode。

v2.0.2 及更早版本需退出旧应用并手动替换应用包一次，保留 `io.providock.app` 数据目录。v2.0.3 起可使用应用内更新。旧 v1 标识独立，不自动迁移账户/统计，也不使用旧更新协议。本版不变更数据库 schema；不会清除本机数据或访问旧 Keychain。

账户 Key 按用户选择明文存在独立本地凭据文件；完整数据目录备份会包含 Key，须保护副本。六条既有本机人民币规则为用户数据，不分发到其他机器。

## 覆盖与边界

八源解析器保持：Claude Code、Codex、Gemini CLI、Grok Build、OpenCode、Pi、MCode、Kimi Code。Codex/Kimi/OpenCode 已有 macOS 真实日志核对，其余以样本验证为主。Windows 构建测试不等于实机运行；网关转发、更多正文读取、导出/清理 UI、通用迁移/回滚、休眠/性能完整验收仍待后续。

更新仅在应用运行期间检查；隐藏窗口可能受系统计时器节流，恢复时补查。网络或签名错误需重试，不承诺自动回滚。GLM 限时优惠和汇率折算应按价格备注复核。

本版代码、CI、资产与原生验证事实见 [核验记录](../research/validation/2026-10-12-release-v2.0.3.md)。

GLM 无 Coding Plan 套餐在账户状态筛选中独立列出，不再归入暂时不可用；保留旧快照时仍优先显示最近的无套餐状态。
