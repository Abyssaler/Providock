# 2026-10-13 本地开发计划

用户要求本轮只做本地开发，不推送、不发行。保留缓存创建统计和现有黑色/黄绿风格。

用户已选择：顶部主导航保留，设置采用左侧分组；官网价格程序优先，用户可主动选择已有 API 账户和模型辅助解析，结果经表单核对后保存。

## 实施范围

1. 统一页面标题与右侧主要操作，精简重复说明；覆盖率、统计口径、来源等低频解释放入少量可键盘访问的提示/详情。错误、过期、未知与部分估算必须仍然可辨认。
2. 用量范围增加滚动 1/3/6 小时，自定义支持本机起止日期时间；汇总、图表、明细共用同一已生效区间，输入无效不触发查询。
3. 依据固定提交的 DeepSeek Harness 官方源码落证据、合成夹具与独立预期，再实现纯解析器、只读发现/扫描、Agent 可见性与页面入口。
4. 接通 Codex 官方 App Server stdio 只读额度查询。添加账户选择本机官方登录；不要求 API Key，不复制 OAuth 令牌，不创建 thread/turn，不驱动推理。
5. AIHOT 改为选择 Agent/模型后获取该模型报价、填入表单，由用户保存；不再批量改写其他模型。支持官网 HTTPS 链接的有界下载和程序解析，必要时用户明确点击模型辅助解析；不执行网页脚本，模型返回仅作候选数据，无工具调用或循环任务。
6. 重整用量、账户、会话、数据源、定价和设置的间距、操作位置、信息层级及窄窗布局。设置按采集/显示/更新与关于分组。
7. 隔离数据验证，运行相关前端/Rust 回归与静态检查、构建及原生/浏览器布局检查；更新产品决定、兼容表、当前状态与 CHANGELOG，记录未验边界。

## 约束

- 用户正式应用/账本/凭据保持独立；验证不改用户价格和账户。
- 九个本地 Agent 与独立账户领域；未知不补零，缓存输入不重复相加。
- 模型辅助解析是用户主动触发的一次 API 请求；只传当前公开价格页内容和目标模型，无本机日志/其他账户信息。
- 本轮不更改历史发行标签、不推送、不发布，Windows 实机结果不得由 macOS 或 CI 推定。
