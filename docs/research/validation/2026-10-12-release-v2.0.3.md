# v2.0.3 发布与安装核验（2026-10-12）

## 接手基线与修复

原 main 为 3544f9b，已有未提交 v2.0.3 候选改动。基线前端 66 项、Rust 349 项通过，4 项真实环境/账户测试忽略；未读取或复用已删除的测试 Key。既有 v2.0.2 标签 d6c1a72 和发布资产保持原样。

接手发现并修复两个问题：Agent 可见性保存缺少 Rust input 包装；趋势图只取首币种，没有查看其他币种的入口。新增真实 invoke 参数回归、双币种提示及未知断点回归。

## 软件更新

新增官方 Tauri updater/process、最小权限、固定 HTTPS v2 清单；控制器测试覆盖检查不安装、显式安装、失败不重启/可重试、并发与卸载资源释放、重启失败。清单测试覆盖两平台 URL、版本、签名结构、与应用端点一致及无效输入拒绝。签名结构检查不代替独立密码学验签。

## 本机与原生候选验证

本机前端 77 项、Rust 349 项通过（4 ignored），TypeScript/Prettier/fmt/Clippy/Vite 通过。隔离标识原生 debug app 构建及 ad-hoc 签名成功；macOS 原生界面确认无旧白色标题栏、显示 v2.0.3，软件更新开关/手动入口可见。取消 Claude Code 勾选后原生设置与数据库 usage.visible_agents 一致，两类调度开关也成功保存；重启后 Claude Code 选项卡保持隐藏，自动同步保持关闭。仅隔离测试库使用 CNY/USD 两币种费率，原生选择从 USD 切至 CNY 后图例与悬浮提示同步为人民币，正式费率库未修改。清单在正式发布前尚不存在，检查失败保留界面并允许重试。

发行、真实签名更新和正式包安装核验已完成，结果如下。

Windows 原生安装/更新仍待实机；控制器模拟不等于真实更新安装。Tauri/minisign 与 Mac ad-hoc 分别核验，不宣称 Apple 公证或 Windows 代码签名。

补充修复 GLM 无套餐筛选分类，回归覆盖存在旧快照的情况；新增更新插件 MIT 许可及依赖许可元数据清单。

## macOS 真实应用内更新

使用带新更新功能、配置版本覆盖为 2.0.2 的隔离标识测试包。正式 GitHub 清单检查返回 v2.0.3，设置入口与用量页新版横幅可见；点击下载后进度更新，经原生签名校验安装正式 app.tar.gz，应用自动重启。升级后磁盘四文件逐一与 CI 相同；运行进程采样的 Mach-O UUID 7D7E2B1C-7272-35F0-9B70-9265224BD60B 与 CI 二进制一致，验证实际运行新版。隔离包升级成正式标识导致 UI 工具旧路径缓存定位失效，使用进程 UUID 独立核对；测试副本随后退出并清理。

首次检查遇网络较慢失败，重试成功；公开端点一次实测 16.9 秒，超过 15 秒检查超时。不能承诺所有网络首轮成功，慢网络需重试。此测试覆盖真实 Mac 通知→下载→签名→安装→重启，不是只模拟控制器；Windows 更新仍无实机证据。
