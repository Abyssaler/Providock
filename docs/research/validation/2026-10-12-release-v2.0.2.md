# v2.0.2 验证与发布核验

## 本机代码与构建

- 52 项前端测试通过，322 项 Rust 测试通过，2 项真实环境/系统凭据测试保持 ignored。
- TypeScript、Prettier、cargo fmt、Clippy 全 targets（deny warnings）、Vite 构建和 Mac ARM64 Dev 应用构建通过；完整 ad-hoc 包严格 codesign 验证通过。
- 新回归覆盖平滑控制点不越过原区间、零/缺失断点、各曲线独立颜色；菜单栏最近 24 小时采用半开范围，覆盖时区偏移、未知时间、未知 Token、排除网关域和 u128 数字精度。
- 合成 IPC 浏览器视觉检查：body 实际背景 rgb(0,0,0)；四分量计算样式分别 rgb(86,180,255)、rgb(69,237,184)、rgb(188,138,255)、rgb(255,190,85)，均为 cubic 曲线。最小 960×800 窗口 clientWidth/scrollWidth 同为 945，无全页横向溢出。
- 图标从原创 assets/app-icon.svg 生成所有既有桌面尺寸；assets/tray-icon.svg 生成 36px PNG/RGBA 供原生模板使用。安装包未引入第三方品牌图标。

## 原生界面边界

已为独立 io.providock.dev 测试标识准备 36 条合成计量事件，两个自动任务关闭；未改正式应用数据。电脑控制工具返回 Computer Use permissions are not granted，未完成原生主窗口关闭、菜单展开/恢复、⌘Q 与菜单退出的人工交互验证。不得把浏览器预览或编译通过描述为原生交互实测。Windows 原生实机、真实账户联网、休眠唤醒、性能仍未验收。

实现依据为 Tauri 2.12.3 本地 API 源码及 [官方系统托盘文档](https://v2.tauri.app/learn/system-tray/)。Mac CloseRequested 调用 prevent_close 与 hide；Dock Reopen/菜单打开恢复 main；退出使用原生默认菜单 ⌘Q 或 app.exit(0)，ExitRequested 取消三个调度任务。Windows 不拦截关窗。
