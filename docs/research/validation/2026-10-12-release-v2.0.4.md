## 实现与验证

统一 Select 代替用量、账户、会话、价格/账户表单的系统原生下拉。macOS 原生测试确认菜单颜色、勾选、鼠标选择、键盘 Home/方向键/Enter、Escape 仅关闭菜单、弹窗内层级正常；补充触发器主动获取焦点以兼容 macOS WebKit 鼠标行为。

默认统计范围已存在：本机当天零点至最近统计刷新，沿用 Agent/来源/模型/时间筛选。页面新增实际查询起止时间与第六张成本卡；缓存比例为已知 read / input_total 的加权值。费用以十进制字符串及 BigInt 四舍五入到两位，超 2^53、进位、零和未知回归通过。源自报费用功能删除，兼容旧 DB 列不清除；IPC/导出不再出现该字段，导出契约 v2。

账户两窗口各自显示标题、数值、重置时间和进度。使用合成的长别名、长来源、5h/7d 百分比测试；1180×800 与 960×640 原生窗口无横向溢出，来源展开仍在本列换行。正式账户未用于布局测试。

AIHOT 合成参考表夹具先于解析器接线；测试覆盖 CNY、来源/汇率、未知与明确免费、极小正价格不变免费、严格匹配/歧义、大小限制/格式变化、重复导入、手动与停用保护、更新追加版本、手动改价清除来源和部分批量写入失败回滚。

真实公开页面只读核验获取 66 个模型中的 56 个可用价格，来源更新时间 2026-10-12T06:06:34.739Z，美元折算汇率 6.6921、日期 2026-10-09。仅在内存库试导入；没有账户请求或推理。

macOS 原生隔离库含 20 条合成用量、1 条手动长上下文规则及两个合成账户。点击一键导入后新增 Kimi/GLM Flash 两条 CNY 规则、保留手动规则、提示一个未知模型；缓存创建价为空。汇总由 37.50 变 304.40 CNY，完整覆盖由 5/20 变 15/20；未知模型不补价。真实应用数据和凭据未参与此测试。
