# ADR 0001：核心边界与技术决策

状态：采纳，依赖版本及适配细节待 P0 验证。日期：2026-10-11。

| 决策 | 理由 | 重新评估条件 |
| --- | --- | --- |
| 本地优先，Tauri 2 / Rust / React / SQLite | 文件、数据库和系统凭据库适合后端统一处理，界面可跨平台复用 | 实际依赖或性能不能满足时，基准比较后换方案 |
| 账户和 Agent 完全分域 | 用户目标是统一监控，不需接入/切换模型 | 用户明确增加配置分发功能，另立需求 |
| 只读日志优先，可选网关默认关闭 | 尽量保留原有工具使用方式；补足 Desktop 条件路径 | 有官方更完整只读源时替换，不静默扩大拦截 |
| 公开官方 / 官方客户端只读接口可用 | 用户接受未公开但有官方依据的能力 | 官方移除或鉴权变化时降级 |
| 仅第三方私有端点暂不接入 | 符合用户选择，避免把逆向能力宣传为官方支持 | 新增官方文档或源码证据 |
| 标准事件账本 + 多证据观察 | 跨源、流式、分叉、复制需要稳定身份与追溯 | 实际不能区分重复/独立请求时修契约 |
| 未知与零、费用与额度分开 | 避免误导余额、缓存命中和订阅支出 | 保持语义，可增强展示 |
| 正文默认不存，可选按需查看 | 满足查看要求，减少敏感数据复制 | 新增全文搜索/归档需求时另做隐私设计 |
| 首版简中、Mac ARM64/Windows x64安装包 | 已确认选择，覆盖常见个人电脑 | 核心稳定后扩展语言/平台/便携版 |
| UI v3.20.4 与功能基线分别固定 | 避免参考设计与当前支持范围混淆 | 用户明确调整视觉方向或更新能力基线 |
| MIT 沿用、历史保留、工作树重新整理 | 用户允许覆盖旧文件，保留恢复与版权依据 | 所有者明确修改许可时审核归属 |

没有选择云端同步、任意脚本查询或系统 TLS 拦截，因为当前目标无需这些能力。未来变更创建新的 ADR，不覆盖历史原因。工程搭建、样本验证或接口审计的未完成项应列任务，不能视为产品范围已经改变。


## 2026-10-11 补充：自动采集与调度控制（D10）

用户明确选择与 cc-switch 相近的运行方式：应用启动自动同步 Agent 日志，随后每 60 秒扫描。此前架构中的文件监听/2 秒去抖/30 秒补扫方案由此替换；八个本地 Agent 的范围和只读边界不变。

采用可唤醒的后台任务：Agent 同步和账户查询独立开关并持久化，关闭时不启用设置轮询；已有任务合并触发，休眠不积压补刷。账户按最近尝试逐个计算余额 15 分钟/计划 5 分钟的截止时间（±10% 抖动），启动首轮也必须检查 enabled。界面的显示刷新只读取本地数据库。这样既能持续监测，也能让用户明确控制后台行为。

## 2026-10-12 补充：v2.0.0 正式发布

维护者明确要求继续构建并发布正式版 v2.0.0，取代尚未发布的 v1.1.0-preview.1 候选。执行为 GitHub 非预发布 Release 并标记 Latest；版本号、发布渠道不作为全功能或实机验收证明，已有缺口继续登记。

版本包取自同一完整提交的双平台成功 CI。macOS 完整 ad-hoc 签名与 Tauri/minisign 更新包签名分别处理；沿用既有发布公钥与 CI Secrets，PR 不使用私钥。暂无 Developer ID/公证或 Authenticode 证书，亦不恢复旧实现的自动更新协议或自动数据迁移。

## 2026-10-12 补充：账户白屏、凭据与模型定价

用户在比较 CC Switch 的明文保存、专用密码加密和仅内存方案后明确选择 A：参考 CC Switch 本地明文保存。生产使用 LocalPlaintextVault，保存于应用数据目录 credentials/keys.sqlite3，与 providock.db 分离；不读取、迁移或删除旧 Keychain 条目。重启直接使用，无应用解锁密码。Unix 目录 0700、文件 0600；Windows 使用用户应用数据目录继承的 ACL，尚未实机验证。此明确产品选择替代原系统凭据库默认；不得将其描述为加密或能阻止同用户权限程序读取。整目录备份会包含明文 Key，统计备份设计须排除此独立文件。

账户嵌套快照统一经过 camelCase IPC DTO；领域及适配器夹具不改名，避免序列化契约破坏。模型定价按 Agent、精确模型和可选数据源，版本追加保存；界面按当前规则比较历史用量，标为估算，不写回源费用或历史估值。

## 2026-10-12 补充：v2.0.2 黑色界面与菜单栏

用户明确要求全局纯黑界面，替代原浅深主题切换；白字、黄绿强调及蓝绿紫橙分量配色贯穿各页。原创 SVG 应用标识与单色模板菜单栏图标可由 Tauri CLI 重建。平滑图采用保持区间的 Hermite 曲线，控制点不越过两端数据范围，避免图形虚构峰谷；缺失值分段保留。

macOS 关闭窗口仅隐藏，保持后台调度；菜单栏与 WebView 独立刷新，展示最近 24 小时本机日志已知小计、八个 Agent 及采集状态。点击菜单打开或 Dock Reopen 恢复，⌘Q/退出停止任务并结束进程。此选择替代原关窗停止调度策略；不安装自启或服务。用户明确授权 v2.0.2 正式 Release 并推送 GitHub，仍不能以正式标签替代 Windows 实机和真实账户验收。

## 2026-10-12 补充：v2.0.3 签名应用更新

用户明确要求 GitHub Release 通知、后续应用内更新以及本次手动换装。采用官方 Tauri updater/process 插件，沿用已有 minisign 公钥与 CI Secret；独立静态清单 providock-v2-latest.json 隔离旧 v1 协议。启动、6 小时间隔和窗口恢复到期时检查，开关仅保存本机 WebView；检查不自动安装，用户点击后验证签名并安装重启。只允许重启权限，不增加任意进程执行、文件访问或 OS 通知权限。检查/下载只访问公开发布服务，不发送账本/账户/凭据。

本版不改变 DB schema。之后存在 schema 变更的更新必须单独设计备份/兼容/恢复门槛；签名不能替代迁移和操作系统代码签名，也不能承诺失败时万能回滚。正式发布授权延续现有人工同 SHA 双平台 CI 验签流程，新增清单必须纳入资产白名单和摘要。

## v2.0.4：成本简化与公开价格导入

按用户要求删除源自报成本功能：领域字段、解析/写入、聚合、IPC、导出及展示均移除。旧 SQLite 列不做破坏性清理，仅留作升级兼容；当前价估算和历史估值保留，统计导出契约显式升至 v2。显示两位小数不改变内部精确金额。

默认日期筛选已有当天口径，沿用并在卡片组标出实际查询起止，不另设隐含一小时口径。Select 采用共享 React 控件，统一菜单与键盘/焦点行为，无新增 UI 依赖。

AIHOT 为用户指定的第三方公开定价来源，不作账户接口依据。只 GET 固定 HTTPS 页，以有界 JSON 参考表解析，不执行脚本；下载后才取 DB 锁，批量保存使用 savepoint。导入使用来源 CNY 值并保存来源/官方链接、抓取/更新时刻和汇率日期；严格匹配，人工或复杂规则优先。上游格式不兼容立即停止，已有规则不动；不推断缺失价格和优惠。

## 2026-10-13：简化界面、九源与单次价格提取

保留顶部主导航，设置改为左侧分组；重复说明按使用点移到少量提示/折叠内容。使用统计增加滚动小时和本机自定义日期时间，已应用筛选统一驱动全部视图。

DeepSeek Harness 是第九个本地 Agent，以官方固定源码证据为依据，session v3/v4 与 .zstd 只读采集，继承父链不明时暂缓，保留历史。Codex 额度采用官方 CLI stdio 的初始化和只读账户 RPC，认证留在官方进程，不复制 OAuth。

本决定替代 v2.0.4 UI 的批量 AIHOT 保存流程：只选目标并预填，用户保存核定规则。价格页用独立公网 HTTPS 客户端；用户可选已有 API 账户、模型触发一次普通补全辅助提取，公开页文本为不可信数据，没有工具或多步任务；字段和原文证据校验后仍需核对。此功能不用于账户余额查询或采集，不引入 Agent 运行时。当前单次模型辅助支持 DeepSeek/GLM/OpenRouter，未执行真实付费推理验收。

本轮按用户要求只本地开发，沿用发行版本，不发布新标签或包。

## 2026-10-13 后续：v2.1.0 发行

用户验收后撤销“仅本地”的阶段限制，明确授权推送 GitHub、发布新版并清理残余。版本为 2.1.0；必须同 SHA 双平台 CI 和签名资产核验，清理只限开发/测试与构建下载，正式账本/凭据及恢复备份保留。

## 2026-10-13 Windows 托盘决定

用户明确要求 Windows 与 Mac 一样关窗继续后台运行。v2.1.1 用 Windows 专用原生托盘替代关窗退出：左键/菜单恢复原窗口，右键退出共用 ExitRequested 调度清理。托盘建立失败不启动，隐藏失败不拦截关闭；Mac 菜单和任务保持。用户授权验证后推送和正式发行，再仅配置本机价格并自行更新正式应用。

## 2026-10-14 D18：结构化价格与中转站

采用 HTML5 DOM 展开价格表合并单元格；同一候选保存币种、调用方式与完整条件。新增 contextTiers（输入/输出半开矩形区间）随 rates_json.strategy 追加；与旧 longContext/peak 互斥，不改 SQLite schema。2026 日历引用国务院安排，未覆盖年份的工作日保持未知，不自动联网推断节假日。辅助模型必须有原文数值证据、结构化策略独立核验，不接受静默取最低档。

New API / One API 使用用户显式配置的 HTTPS 站点与官方只读协议，不写统一第三方域名白名单；生产为该次请求固定公网 DNS 并拒绝重定向。非秘密 RelayConfig 保存于 credential capabilities，Key 仍在独立 vault；轮换继承配置。现金换算率必须由用户确认，不预设 500000，更不依赖旧 billing 的 USD 字段名。Key/账户范围分开；仅实际返回 user_quota 才显示 Key 获准读取的账户范围。
